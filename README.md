# Joan Orobio — Sitio personal

Portafolio de **Ingeniero de Aprendizaje Automático** y **Científico de Datos**.

## Ver en local

Abre `site/index.html` en el navegador, o sirve la carpeta `site`:

```bash
npx serve site
```

## Deploy en Netlify

El archivo `netlify.toml` publica la carpeta `site`. Conecta este repo a Netlify y haz deploy.
